# ProjectManager
React Project Manager: A modern task and project management SPA built with React, focusing on efficient form handling and state management.

Project Overview
This Project Manager is a clean, single-page application (SPA) built with React for organizing projects and tracking associated tasks. It serves as a practical demonstration of advanced React Hooks and imperative DOM interaction.

Key Features
Project Creation: Add new projects with custom titles and due dates.

Task Management: Add and remove individual tasks associated with any active project.

Project Selection: Intuitive state management for selecting and focusing on one project at a time.

Efficient Form Handling: Implements uncontrolled components for optimal performance on final submissio
